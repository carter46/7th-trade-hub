# PWA Icons

Brand icons for install and home screen:

- **icon-192x192.png** (192×192 px) — committed
- **icon-512x512.png** (512×512 px) — committed

Optional: `icon-maskable.png` (512×512, maskable for Android).

The manifest references `/icons/icon-512x512.png` and `/icons/icon-192x192.png`.

These files are regenerated from **Admin → Settings → Site branding** (favicon preferred, otherwise light/dark logo) when you save branding. After changing the logo/favicon, save branding again, then reinstall the PWA/APK if the old icon is still cached.
